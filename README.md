# Productivity OS

A personal operating system for planning, focus, execution, progress, and reflection.

This repository is also an experiment in **Spec-Driven Development (SDD) with AI**.

## Development Philosophy

```text
Idea
  -> Specification
  -> Specification Review
  -> Architecture / ADR
  -> Implementation Plan
  -> Implementation
  -> Verification
  -> Human Review
  -> Ship
  -> Experiment / Learn
```

The specification describes **what and why**. The implementation plan describes
**how** the current implementation will be built.

## Repository

- `AGENTS.md` — instructions for AI coding agents
- `docs/product/` — product vision and principles
- `docs/specs/` — approved product behavior
- `docs/architecture/` — system design
- `docs/decisions/` — architecture decisions
- `docs/plans/` — implementation plans
- `docs/experiments/` — SDD experiments and findings
