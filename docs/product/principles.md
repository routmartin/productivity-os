# Product Principles

## 1. Outcomes over activity

Completing many tasks does not necessarily mean making progress.

## 2. Focus over task volume

The system should reduce the number of things competing for the user's attention.

## 3. Planning over reacting

The system should encourage users to think ahead.

## 4. Reality over optimism

Plans should account for actual available capacity.

## 5. Progress over completion

Progress toward meaningful goals matters more than raw task counts.

## 6. Reflection over guilt

The system should help users understand why plans failed, not make them feel bad.

## 7. Automation over administration

The user should spend as little time as possible managing the productivity system itself.

## 8. AI assists judgment

AI should help the user think and decide, not silently make important decisions.
