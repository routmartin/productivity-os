# EXP-001: Specification Before Implementation

## Status

Planned

## Hypothesis

Writing and approving a specification before implementation will reduce AI
implementation rework and make changes easier for a human to review.

## Feature

Daily Top 3

## Method

Compare a structured workflow:

```text
Specification
-> Specification Review
-> Architecture / Plan
-> Implementation
-> Verification
-> Human Review
```

against a future less-structured implementation workflow if useful.

## Metrics

Track:

- implementation iterations
- development time
- number of files changed
- bugs discovered during review
- specification changes after implementation begins
- human review time
- acceptance criteria pass rate
- unrelated changes introduced by AI

## Success Criteria

The structured workflow should provide:

1. Clear traceability from requirements to implementation.
2. Fewer unnecessary implementation iterations.
3. Easier human review.
4. Explicit handling of ambiguity.
