# Architecture Decision Records

ADRs record significant technical decisions and their reasoning.

## When to create an ADR

Create an ADR when a decision:
- affects architecture
- introduces a major dependency
- creates a significant trade-off
- changes an established architectural pattern
- would be difficult to reverse

## ADR Lifecycle

```text
Proposed -> Accepted
         -> Rejected
         -> Superseded
```
